# EventMonitorUnal
# Descripción

Sistema desarrollado en Java para gestionar espacios universitarios, administrar reservas y consultar la disponibilidad de los espacios.

# Funcionalidades

Registrar y listar espacios universitarios.

Crear reservas con fecha y hora.

Evitar reservas superpuestas.

Consultar disponibilidad de los espacios.

Consultar el historial de reservas.

Ordenar espacios por cantidad de reservas.

Combinar espacios compatibles.

# Tecnologías

Java 17 o superior.

Programación orientada a objetos (POO).

Estructuras de datos: HashMap, TreeMap, ArrayList y HashSet.
